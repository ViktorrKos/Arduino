# Назва завдання (Сфітлофор з миготінням)

Червоний: 2 секунди, миготіння 3 рази.
﻿﻿Жовтий: 2 секунди, миготіння 1 раз.
﻿﻿Зелений: 2 секунди, миготіння 4 рази.
﻿﻿Фіолетовий: 1 секунда, миготів якщо попередній колір був червоним.

## 🛠 Компоненти
- Arduino Uno
- Макетна плата
- Резистор 220 ОМ
- LED
